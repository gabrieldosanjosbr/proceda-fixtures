# PROCEDA Fixtures

Fixtures, factories e builders para geração de dados de teste compatíveis com o [PROCEDA](https://github.com/gabrieldosanjosbr/proceda).

O pacote fornece ferramentas para criar objetos do modelo de domínio do PROCEDA preenchidos com dados fictícios, facilitando testes automatizados, exemplos e ambientes de desenvolvimento.

## Instalação

```bash
composer require --dev proceda/fixtures
